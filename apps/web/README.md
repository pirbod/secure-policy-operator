# Customer Cloud Policy Operator Web App

React, TypeScript, Vite, Tailwind CSS, Recharts, and lucide-react power the local clickable demo.

## Run

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 5173
```

The app expects the API at `http://localhost:8000`. Override with `VITE_API_BASE_URL` when needed.
